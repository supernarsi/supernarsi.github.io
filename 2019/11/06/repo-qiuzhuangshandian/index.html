宏宇宙中的微感受

发表于 2019-11-06 分类于 书评 阅读次数： Disqus：
《球状闪电》读书笔记。看完书的时候是凌晨两点多，恰巧那天是个雨夜，虽然没有电闪雷鸣，更没有出现可怕的球状闪电，但深夜的宁静和窗外的雨声相映，让人想起书中开篇时「我」的那个生日雨夜，不免产生一种恍惚感，好像两个世界重叠在了一起。

看完书的时候是凌晨两点多，恰巧那天是个雨夜，虽然没有电闪雷鸣，更没有出现可怕的球状闪电，但深夜的宁静和窗外的雨声相映，让人想起书中开篇时「我」的那个生日雨夜，不免产生一种恍惚感，好像两个世界重叠在了一起。

《球状闪电》带给我的思考量和认知更迭不如《三体》多，但在情感上却更让我感到亲近，就像是眺望恢弘的建筑奇迹和游览别致的园林景观带给人的体验有所区别一样，两者虽说在内核上一脉相承，但是最终的呈现却大相径庭。如果说三体目的在于构建一个庞大的世界观，球闪则是在侧重描述人生观，我们跟随书中人物进行更多的不是哲学思考，而是人性思考，比如陈博士对人生和事业追求的几次转折、比如核电站事件首长的态度、也比如林云最后的选择，这些其实完全是与科幻背景解耦的，甚至可以将它们糅合进其他的都市言情小说里也不显突兀，所以说球状闪电更让人亲近，这里没有遥远的无敌水滴，没有超越常识的曲率驱动飞船，有的只是普通军人、科研工作者、物理学家们痛苦但坚定地追求目标和探寻真理。

但这并不代表《球状闪电》的科幻不够「硬」、构思不够巧妙，恰恰相反，因为科幻部分主要都只是围绕球状闪电展开，而不用试图全面地去诠释宇宙，因此它在细节上甚至比《三体》更能逻辑自洽（特别是在观察者导致宏观现象发生坍缩这一设定，还一度让我进行了很漫长的哲科思考），以至于让我感到在科幻想象力层面它已经趋近于完美了。于是我也只能很刻意地从文学性层面挑一挑刺，当然这方面一向是大刘的短板，特别是对于女性角色的人物塑造，更是刺中刺，林云本身的经历导致她最终的行为原本是可以很有说服力的，但在塑造她时，大刘仿佛只是在简单的堆砌特质，为了让那些特质更有说服力还强加上一些荒诞的行为，比如车上的竹节，佩戴胸前的剑章，以及在军队中的越级行权，可这些细节并没有起到佐证她偏执的作用，反而因为过于荒唐让人读来没有真实感，至于白衬衫白牛仔裤的雷雨「女神」形象，更是既滑稽又老套。

最后还是要赞美下这本书中的理科式浪漫与诗意，比如宏原子的弦舞、宏聚变后的镜面以及郑教授的量子公式。当丁仪解释球状闪电的本质和释能原理时，真给我一种朝闻道的震撼感，如同一道看似让人毫无头绪的难题，最后发现答案十分简单而又巧妙合理一样，让人如沐春风。
